# 工程行为安全检测系统

本机 Web 控制台：摄像机主界面、五项检测开关、人员白名单/黑名单、红色文字报警。声音报警控件可见但不可用。

## 启动

双击项目根目录的 `start.bat` 启动，双击 `stop.bat` 关闭。`start.bat` 会先停掉旧进程，再启动后端和页面，并打开 http://127.0.0.1:5173/ 。改完代码后再次双击 `start.bat` 即可重新验证。后端带自动重载，前端保存后也会自动刷新。

首次使用先安装依赖：

```powershell
cd backend
pip install -r requirements.txt
cd ..\frontend
npm install
```

若已执行 `npm run build`，也可只启动后端，打开 http://127.0.0.1:8000 。

## 说明

- 检测项默认全部关闭，并按当前环境分别保存。
- 只有已开启的检测项可以模拟报警；报警以红色文字出现在主界面，并写入报警记录。
- 每个环境可连接本机摄像头，或填写网络摄像头地址（海康主码流示例：`rtsp://账号:密码@IP:554/Streaming/Channels/101`）。切换环境会切到该环境已保存的摄像头。
- 摄像机下方显示当前环境已开启的检测项。
- 顶栏选择环境。每个环境单独保存检测开关和摄像头，可以新增环境，也可以改名。
- 检测项有五项：人员检测、二维码工号检测（9 位数字）、安全护具佩戴检测、危险动作检测、二维码工器具检测（6 位数字）。
- 工号二维码命中黑名单或资质过期会报警。器具二维码未录入或检定到期会报警。
- 危险动作检测识别作业中接打电话。面向摄像头，把手机贴在耳侧约 1 秒。
